# Linux Guides

Практические инструкции по настройке домашнего ПК на Arch Linux / Omarchy: эмуляторы и локальный ИИ на GPU. Всё написано по шагам и проверено на реальной машине — не теория, а рабочая последовательность действий вместе с граблями, на которые пришлось наступить.

**Железо и система, на которых всё проверялось:**

- CPU: AMD Ryzen 5 5600X
- GPU: AMD Radeon RX 5600 XT (Navi 10 / gfx1010), 6 ГБ VRAM, Mesa RADV
- Экран: 2560×1440
- ОС: Omarchy 4.5 (Arch Linux)

## Инструкции

| Инструкция | О чём |
|---|---|
| **[Ollama на AMD RX 5600 XT через Vulkan](ollama-vulkan-amd.md)** | Локальные LLM на GPU без ROCm: почему ROCm не подходит для Navi 10, установка `ollama-vulkan`, systemd drop-in, проверка `100% GPU`, подбор моделей под 6 ГБ VRAM, тонкая настройка и полный откат. |
| **[PCSX2 + Silent Hill 2](pcsx2-setup.md)** | Эмулятор PS2 на Arch: установка из AUR, BIOS, образ игры, Vulkan-рендер с апскейлом 3x, геймпад Logitech F310, карты памяти, ярлык запуска в меню Omarchy с обложкой. |
| **[Cemu + Breath of the Wild](cemu-botw.md)** | Эмулятор Wii U: нативный Linux-билд, графические паки и FPS++, исправление зависаний на «loading…», звук через Cubeb, настройка DualSense, 60 fps в 2560×1440. |

## Важно

Инструкции привязаны к конкретной конфигурации (Ryzen 5 5600X + RX 5600 XT, Omarchy/Arch). Команды и пути стоит адаптировать под своё железо: например, вместо конкретного аудиоустройства или пути к образу подставить свои. В текстах есть команды для просмотра своих значений — `pactl list short sinks`, `vulkaninfo --summary`, `pacman -Q` и т. п.

Пути в примерах указаны для пользователя `sansheng` — замените на своё имя пользователя.

BIOS, образы игр, ключи и прочие файлы, защищённые авторским правом, в репозиторий не входят и не распространяются: инструкции предполагают, что дампы у вас уже есть и сделаны с собственных носителей.
